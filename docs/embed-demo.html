Embed Demo — Anime Servers

This demo shows two anime embed iframes: the default server (VidPlus) and an alternate server (MineCloud). The site's configuration sets VidPlus as the default server in _data/player.yml.

Default — VidPlus

Base: https://player.vidplus.to/embed

Example: /embed/anime/{anilistId}/{episode}?dub={true/false}

Alternate — MineCloud

Base: https://player.minecloud.to/embed

Replace player.minecloud.to with your server's embed domain.

How to use in your site

// Use default (VidPlus)
<iframe src="https://player.vidplus.to/embed/anime/21/1?autoplay=true" frameborder="0" allowfullscreen></iframe>

// Use alternate server (MineCloud)
<iframe src="https://player.minecloud.to/embed/anime/21/1?autoplay=true" frameborder="0" allowfullscreen></iframe>

Note: The site configuration file (_data/player.yml) lists available servers and the default_server. You can update templates or a small script to read the default value and render the correct iframe by default.
