# AnimeVault Mobile Frontend

Fresh React Native/Expo frontend for the Movies, TV Shows and Dramas experience.

This phase intentionally uses mock/example content only. No production API, authentication, database, or streaming connection is included yet.

## Design
- AniWatch-inspired browsing density and mobile-first UX
- AnimeVault black + neon-pink identity
- Movies, TV Shows and Dramas only
- Feature-parity screens will be added before backend integration

## Run
```bash
cd mobile-app
npm install
npx expo start
```
